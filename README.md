# Chatmate 交互设计稿

在线预览：https://gao725216-afk.github.io/chatmate-preview/

9 份设计稿合并为一个 `index.html`，包含 47 个页面的浅色与深色版本，共 94 个画面。保留原稿样式、内嵌 SVG 和交互逻辑，并将 612 处页面链接接入单文件路由。

- 顶部切换模块、画面与主题；点击画面内链接可跨模块浏览。
- 地址栏 hash 可直接定位某个画面，例如 `#V2Start`、`#V2DesktopHome`。
- 单文件可下载后在浏览器打开，无需安装或构建。字体使用 Google Fonts；断网时回退系统字体。
- 这是交互设计演示，登录、聊天、翻译等使用示例内容，不连接真实业务后端。

GitHub Pages 从 `main` 分支根目录发布。
